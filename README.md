# Portfolio — Your Name

A personal portfolio website built with vanilla HTML, CSS, and JavaScript.

## 📁 Project Structure

```
Portfolio/
├── index.html          ← Main entry point
├── css/
│   └── style.css       ← All styles & design tokens
├── js/
│   └── main.js         ← Interactions, animations, form logic
├── assets/
│   ├── resume.pdf      ← Place your resume here
│   └── images/         ← Place project images here
└── README.md
```

## 🚀 How to View Locally

Simply open `index.html` in your browser — no build step needed.

Or use the VS Code **Live Server** extension:
1. Right-click `index.html` → **Open with Live Server**

## 🌐 How to Deploy (Free Hosting Options)

### Option 1 — GitHub Pages (Recommended)
1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set **Source** to `main` branch, `/ (root)`.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>`.

### Option 2 — Netlify
1. Drag and drop this folder at [app.netlify.com/drop](https://app.netlify.com/drop).
2. Your site is instantly live with a free URL.

### Option 3 — Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory and follow the prompts.
